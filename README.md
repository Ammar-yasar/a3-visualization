# Cinema Analytics — Interactive Visualization

An interactive data visualization built with D3.js for Assignment 3.

## Dataset
IMDB Movies Dataset (3,201 records) sourced from [vega-datasets](https://github.com/vega/vega-datasets).  
Attributes include: Title, Genre, IMDB Rating, Rotten Tomatoes Score, Worldwide Gross, Production Budget, and Release Year.

## Interaction Types Implemented
| # | Type | Description |
|---|------|-------------|
| 1 | **Select** | Click a dot to highlight it |
| 2 | **Filter** | Filter by genre and release year |
| 3 | **Encode** | Change color mapping (Genre / Rating / Gross) |
| 4 | **Connect** | Hover a dot to highlight the matching bar |
| 5 | **Reconfigure** | Swap or change the X/Y axes |
| 6 | **Elaborate** | Click a dot to see full movie details |
| 7 | **Abstract** | Toggle between raw points and aggregated view |
